## 产品实践 · got it

### [哪句不懂，划哪句](https://gotit.bingbryan.com/)

选中文字或框选 PDF，在原句旁直接提问、查证并留存

- **解释一下：** 说明陌生概念或难懂段落，帮助理解原意。
- **查找来源：** 寻找数字、观点的出处，查看资料是否支持原句。
- **问一问：** 围绕选区提出具体问题，回答留在原句旁，方便回看。
